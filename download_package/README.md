# 名探偵コナン トレーディングカードゲーム - ダウンロード版

AIと対戦可能な名探偵コナンTCGクローンゲーム（スタンドアロン版）

## 遊び方

### 起動方法

1. このフォルダ内の **`index.html`** をブラウザで開く
2. メニューから遊びたいモードを選択

### 3つのゲームモード

#### 1. ⚔️ バトル（カスタムデッキ）
- デッキビルダーで作成したカスタムデッキで対戦
- デッキが未作成の場合は自動的にデフォルトデッキを使用

#### 2. 🎴 デッキビルダー
- 40枚のデッキを自由に構築
- 色・レベル・タイプで絞り込み
- 名前・AP・LPでソート
- 同じカードは3枚まで
- LocalStorageに自動保存

#### 3. 🎮 クイックプレイ
- デフォルトデッキで即プレイ
- ルールを学ぶのに最適

## ゲームの目的

証拠を集めて事件を解決し、勝利を目指します。

### 勝利条件

1. **第1段階**: FILEエリアを7枚にして、パートナーの「アシスト」で解決フェーズに移行
2. **第2段階**: 証拠を7枚（後攻なら6枚）集めて、「事件解決」を宣言

## カードの見方

**キャラクターカード**
- **Lv**: プレイに必要なFILE枚数
- **AP**: 攻撃力/防御力
- **LP**: 推理力（証拠獲得数）

**イベントカード**
- **Lv**: プレイに必要なFILE枚数
- **効果**: 発動する効果

## デッキビルダーの使い方

1. **カードを選ぶ**
   - 色ボタンで絞り込み（赤/青/黄/緑/白/黒）
   - ソート順を選択（レベル/名前/AP/LP）

2. **デッキを作る**
   - カードをクリックして追加（3枚まで）
   - デッキは40枚必要

3. **保存してバトル**
   - 「💾 デッキ保存」で保存
   - 「⚔️ バトル開始」でバトル画面へ

## 戦略のヒント

1. **序盤**: レベル1のキャラをプレイして場を固める
2. **中盤**: 推理で証拠を集めつつ、相手を妨害
3. **終盤**: FILE 7枚で解決フェーズへ、証拠を集めて事件解決
4. **デッキ構築**: LPが高いキャラを多めに、イベントで妨害も重要

## 動作環境

- モダンブラウザ（Chrome, Firefox, Safari, Edgeなど）
- インターネット接続不要
- インストール不要

# 名探偵コナンTCG - ダウンロード版

## 📦 内容

このパッケージには以下のファイルが含まれています：

- `game.html` - ゲーム本体（ブラウザで開くだけでプレイ可能）
- `server.js` - WEBサーバー（オプション）
- `README_DOWNLOAD.md` - このファイル

## 🎮 遊び方（2つの方法）

### 方法1: 直接ブラウザで開く（推奨・簡単）

1. `game.html` をダブルクリック、またはブラウザにドラッグ&ドロップ
2. すぐにプレイ開始！

**必要なもの:** ブラウザのみ（Chrome, Firefox, Safari, Edgeなど）

---

### 方法2: WEBサーバーで起動

1. Node.jsをインストール（未インストールの場合）
2. ターミナル/コマンドプロンプトで以下を実行：

```bash
node server.js
```

3. ブラウザで `http://localhost:3000` を開く

**必要なもの:** Node.js（無料でダウンロード可能）

---

## 🎯 ゲームの遊び方

### 基本ルール

1. **目的**: 証拠を7枚集めて事件を解決する（後攻は6枚）
2. **手順**:
   - FILEを7枚集める → アシストで「解決フェーズ」へ
   - 推理で証拠を集める → 事件解決で勝利！

### 操作方法

- **カード選択**: 手札をクリック（青くハイライト）
- **カードをプレイ**: キャラやイベントを場に出す
- **推理する**: 証拠を集める（選択カードのLP値分）
- **アクション（攻撃）**: 相手の証拠を減らす
- **アシスト**: FILE 7枚で解決フェーズへ
- **事件解決**: 勝利宣言！
- **ターン終了**: AIのターンへ

### 勝利への流れ

```
1. キャラをプレイ（レベル1から）
   ↓
2. 推理で証拠を集める
   ↓
3. FILEが7枚になったらアシスト
   ↓
4. 証拠7枚（後攻6枚）で事件解決
   ↓
5. 勝利！
```

## 💡 攻略のヒント

1. **序盤**: レベル1キャラを素早く場に出す
2. **中盤**: LPが高いキャラで推理を優先
3. **FILE管理**: 7枚溜まったらすぐアシスト
4. **妨害**: 相手の証拠が増えたら「混乱」で減らす
5. **バランス**: 推理と攻撃のバランスが重要

## 🔧 トラブルシューティング

### ゲームが開かない
- 最新のブラウザを使用してください
- JavaScriptが有効になっているか確認

### サーバーが起動しない
- Node.jsがインストールされているか確認
- ポート3000が使用中の場合、server.jsのPORT番号を変更

### カードが選択できない
- ブラウザを更新（F5キー）
- キャッシュをクリア

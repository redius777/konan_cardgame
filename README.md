# 名探偵コナン トレーディングカードゲーム クローン

AIと対戦可能な名探偵コナンTCGクローンゲーム

## 概要

タカラトミーの「名探偵コナン トレーディングカードゲーム」を参考にした、ブラウザとコンソールで遊べるゲームです。

### 主な機能

- **2段階の勝利システム**: FILEを集めて解決フェーズへ、証拠を集めて事件解決
- **戦略的なカードバトル**: キャラクターの推理力（LP）と攻撃力（AP）を駆使
- **AIとの対戦**: 基本的な戦略を持つAIと対戦
- **14種類のキャラクター**: コナン、平次、灰原、キッドなど人気キャラ
- **5種類のイベントカード**: 推理ショー、混乱など戦況を変える効果
- **ブラウザ版**: クリック操作で直感的にプレイ
- **コンソール版**: ターミナルで対話的にプレイ

## 🎮 3つの遊び方

### 方法1: ブラウザ版（推奨・最も簡単）

**WEBサーバーで起動:**
```bash
npm install
npm run web
```

ブラウザで `http://localhost:3000` を開く → 即プレイ！

### 方法2: ダウンロード版（サーバー不要）

1. `conan-tcg-game.zip` をダウンロード＆解凍
2. `game.html` をブラウザで開く
3. すぐにプレイ開始！

**必要なもの:** ブラウザのみ

### 方法3: コンソール版（ターミナル）

```bash
npm install
npm run build
npm start
```

ターミナルで対話的にプレイ

## 遊び方

### ゲームの目的

証拠を集めて事件を解決し、勝利を目指します。

### 勝利条件

1. **第1段階**: FILEエリアを7枚にして、パートナーの「アシスト」で事件を解決フェーズに移行
2. **第2段階**: 証拠を7枚（後攻なら6枚）集めて、「事件解決」を宣言

### ターンの流れ

#### オートフェーズ（自動）
1. Sleep状態のカードをActiveに戻す
2. デッキからFILEエリアに2枚追加（初回は1枚）
3. 1枚ドロー

#### メインフェーズ（プレイヤーの行動）
- **キャラクターをプレイ**: 手札からキャラを場に出す（FILEのレベル制限あり）
- **イベントをプレイ**: 効果を発動
- **推理**: キャラをSleepにしてLP分の証拠を獲得
- **アクション**: キャラをSleepにして攻撃（証拠操作）
- **パートナーのアシスト**: FILEが7枚で解決フェーズへ
- **事件解決**: 勝利宣言

### カードの見方

**キャラクターカード**
- **Lv**: プレイに必要なFILE枚数
- **AP**: 攻撃力/防御力（バトルで使用）
- **LP**: 推理力（推理時に得られる証拠数）

**イベントカード**
- **Lv**: プレイに必要なFILE枚数
- **効果**: 発動する効果

### 戦略のヒント

1. **序盤**: レベル1のキャラをプレイして場を固める
2. **中盤**: 推理で証拠を集めつつ、相手を妨害
3. **終盤**: FILE 7枚で解決フェーズへ、証拠を集めて事件解決
